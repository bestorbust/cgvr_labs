# CGVR Labs

## Computer Graphics and Virtual Reality

This repository contains the laboratory programs and experiments completed as part of the **Computer Graphics and Virtual Reality (CGVR)** course.

Each laboratory experiment is organized into a separate folder such as `lab1`, `lab2`, `lab3`, and so on.

---

## 🛠️ Technologies Used

The laboratory programs primarily use:

* **Python 3.14.3**
* **OpenGL / PyOpenGL**
* **GLUT**
* **NumPy**

Individual experiments may use additional libraries when required.

---

## ⚙️ Setup

The programs are designed to run using the **local Python installation**. No virtual environment is required.

### Python Version

```text
Python 3.14.3
```

Verify the installed Python version using:

```bash
python --version
```

or:

```bash
py --version
```

### Install Dependencies

Install the required Python packages using:

```bash
python -m pip install PyOpenGL PyOpenGL_accelerate numpy
```

Additional dependencies, if required by a particular laboratory, can be installed separately.

---

## ▶️ Running a Lab

Navigate to the required laboratory folder:

```bash
cd lab3
```

Run the required Python program:

```bash
python filename.py
```

For example:

```bash
python transformations.py
```

The programs use the local Python installation directly.

## 🎯 Objective

The objective of this repository is to maintain the practical implementations and experiments performed as part of the **Computer Graphics and Virtual Reality** course.

The experiments focus on understanding and implementing fundamental computer graphics concepts, algorithms, transformations, and rendering techniques.
